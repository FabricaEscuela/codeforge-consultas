# CodeForge · API de Consultas

API REST de solo lectura que entrega el feed de la red social.

**Despliegue:** https://codeforge-consultas.onrender.com

## Tecnologías
Java 21 · Spring Boot · Maven · PostgreSQL · Docker

## Endpoints principales
| Método | Ruta | Descripción |
|---|---|---|
| GET | `/api/v1/feed` | Feed con los proyectos y discusiones de los usuarios que sigues |
